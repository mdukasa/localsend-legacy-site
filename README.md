# LocalSend Legacy website

The website for [LocalSend Legacy](https://github.com/mdukasa/localsend-legacy), styled like an app
site from around 2011. Plain HTML and CSS, no build step, hosted on Vercel at https://localsend-legacy.vercel.app.
Every push to `main` deploys automatically.

Preview locally:

```
python -m http.server 8000
```
